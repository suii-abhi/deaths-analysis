# Cardiovascular Deaths Analysis

Analysis of global cardiovascular death data (2015-2019).

**What I did:**
- Cleaned messy dataset with 35 columns → 4 columns
- Wrote SQL queries to find top countries
- Built interactive dashboard in Tableau

**Files:**
- `cardio_death.csv` - Cleaned data
- [Tableau Dashboard](https://public.tableau.com/authoring/CardiovascularDeathsAnalysis/Sheet1#1)

**Key Finding:**
China has the highest cardiovascular deaths globally, followed by India and the USA.

## Tools Used

- **Python** - Pandas for data cleaning
- **SQL** - SQLite for querying
- **Tableau** - Interactive visualization
